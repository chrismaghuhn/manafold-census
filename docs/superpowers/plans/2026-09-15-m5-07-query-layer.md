# M5-07 Read-only Query Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a validated, read-only query module that exposes deterministic
card semantic views and complete cross-layer traces from a frozen M5-06 Census
tree.

**Architecture:** `open_bundle(path)` is the only public construction seam.
It fully validates the self-contained M5-06 tree through the existing M5-05,
M5-02, M5-03, M5-04, and M5-06 validators before loading typed records. The
reader keeps immutable in-memory joins for read-only queries. `cards.py` owns
the closed `SemanticStateV1` model and its normative M3-first precedence;
`provenance.py` owns deterministic M3/M2/M4 trace assembly. Query methods never
parse Oracle text, create authority, mutate files, access the network, or run
Magic rules.

**Tech Stack:** Python 3.12+, existing canonical JSON and frozen M1/M3/M4/M5
models/validators, pytest, Ruff, mypy, PowerShell.

def semantic_state_for(outcome, requirement_count, mapped_requirement_count):
